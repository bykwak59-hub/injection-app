[사출조건 최적화 앱 - 안드로이드 홈 화면 설치 방법]

이 폴더의 파일은 https 주소의 웹 서버에 올려야 "앱 설치"가 됩니다.
(휴대폰에서 파일을 직접 열면 아이콘 설치/오프라인 기능이 동작하지 않습니다)

■ 방법 1. GitHub Pages (무료, 영구)
 1) github.com 에서 새 저장소 생성 (예: injection-app, Public)
 2) "Add file > Upload files" 로 이 폴더의 파일 전부 업로드
 3) Settings > Pages > Branch: main / (root) 선택 후 Save
 4) 1~2분 뒤 https://<아이디>.github.io/injection-app/ 주소 생성

■ 방법 2. Netlify Drop
 1) app.netlify.com/drop 접속 (무료 가입)
 2) 이 폴더를 통째로 끌어다 놓기 → https 주소 생성

■ 휴대폰에 설치
 1) 안드로이드 Chrome으로 위 주소 접속
 2) 하단 "홈 화면에 앱 설치" 배너의 [설치] 누르기
    (배너가 안 보이면 Chrome 메뉴 ⋮ > "앱 설치" 또는 "홈 화면에 추가")
 3) 홈 화면에 생긴 "사출조건" 아이콘으로 실행 → 전체화면 앱처럼 동작
 4) 한 번 실행한 뒤에는 인터넷이 없어도 사용 가능

※ 입력값·재질/사출기 데이터는 휴대폰 안에 저장됩니다.
※ 앱을 수정해 다시 올릴 때는 sw.js 첫 줄의 'injection-v1' 숫자를 올려주세요.
